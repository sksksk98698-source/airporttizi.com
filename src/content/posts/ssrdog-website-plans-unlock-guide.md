## 七、 日常使用高频疑难杂症与极速排错指南

掌握以下四个常见场景的排查要领，99% 的网络问题都能在 30 秒内迎刃而解：

### 7.1 订阅更新提示 500/403 或内容为空的解决方案

- **排查 1：套餐是否已经到期或流量耗尽**：登录 SSRDOG 官网后台，查看仪表盘中的套餐状态和剩余流量；
- **排查 2：本地客户端节点死循环代理**：先将客户端模式切换为“直连”，或者暂时关闭系统代理，然后再点击“更新订阅”；
- **排查 3：订阅转换后端故障**：如果使用了第三方 Subconverter 转换，可能该后端节点被墙。建议在 SSRDOG 后台直接复制原生客户端订阅直连。

### 7.2 网页能开但 ChatGPT 提示 Access Denied 的快速切换技巧

- **核心原因**：某些节点的 IP 可能刚好被其他用户触发了高频 API 爬虫，导致临时进入 OpenAI 观察名单；
- **解决技巧**：在客户端中将策略组手动从“香港”切换至“日本 01”或“美国 01”，随后在浏览器中**彻底清除 `chatgpt.com` 的 Cookies 缓存**，或开启浏览器无痕隐身窗口重新打开，即可秒进。

### 7.3 WebRTC 真实真实 IP 泄露防御与本地 DNS 防污染配置

在浏览器（如 Chrome、Edge、Firefox）中使用代理时，由于 WebRTC 协议允许通过 STUN/TURN 服务器直连，可能会绕过本地代理直接泄露本地公网真实 IP：
1. **安装防护扩展**：在浏览器商店安装 **WebRTC Control** 或 **uBlock Origin**，在设置中勾选“阻止 WebRTC 泄露本地 IP 地址”；
2. **DNS 防污染配置**：确保 Clash Verge 中启用了 `enhanced-mode: fake-ip`。Fake-IP 机制能够在浏览器发起真实 DNS 查询之前直接返回一个虚拟 IP（如 `198.18.0.x`），所有真实解析均推迟至 SSRDOG 境外落地机房完成，彻底绝杀本地运营商 DNS 污染与重定向。

### 7.4 IPv6 漏网导致代理绕过排障指南

部分国内运营商在开通家宽时默认分配了公网 IPv6 地址。部分客户端在处理双栈网络时，可能会优先走 IPv6 直连通道出境，导致本该代理的境外流量裸奔出境并被防火墙直接丢包：
- **处理建议**：在 Clash Verge 或小火箭设置中，将 **IPv6 开关彻底关闭**；或者在路由器后台禁用 IPv6 分配。纯 IPv4 环境不仅能有效避免各种玄学断流，还能显著提升 DNS 解析起播速度。

#### Q3：SSRDOG 机场和花云、TAG 相比，我该怎么选？

#### Q4：SSRDOG 机场支持按量付费或一次性买断不限时流量包吗？
**答**：目前 SSRDOG 机场的核心服务完全基于高成本的内网 IPLC 物理专线构建，这类专线资源属于每月固定月租采购的高规格商业物理链路。因此，SSRDOG 目前主要采用月付、季付与年付的周期计费模式，并不提供低价的长期不限时按量流量包。如果您是极低频使用、几个月仅查一次邮件的用户，这类纯专线周期订阅可能并非性价比最高的选择；但如果您是每天都需要稳定出海的科研工作者、外贸从业人员或流媒体重度用户，其带来的稳定性和无感连接体验绝对物超所值。

#### Q5：在移动设备（iOS / Android）上使用 SSRDOG 时，如何避免耗电过快和后台被杀？
**答**：由于 SSRDOG 采用轻量且高效的原生代理协议（Shadowsocks / V2Ray 协议簇），其本身对系统资源的消耗极低。为获得最佳续航与长连接稳定性，建议注意以下三点：
1. **合理配置健康检查探针间隔**：在 Clash Verge Rev 或 Shadowrocket 中，将节点自动健康检查（URL-Test / Health Check）的时间间隔由默认的 180 秒调大至 600 秒或改为仅在手动需要时刷新，避免移动端在息屏状态下被代理核心频繁唤醒造成无线电基带耗电；
2. **正确开启路由直连规则**：确保国内常见应用（微信、高德地图、淘宝、飞书等）完全走 `DIRECT` 直连通道，不仅可以显著节省机场每月的高速专线流量，还能免除代理核心对高频国内数据包的解包与转发开销；
3. **Android 端设置电池白名单**：在 Android 手机（如小米 HyperOS、华为 HarmonyOS、vivo OriginOS 等）的系统设置中，将 Clash Meta for Android 或 sing-box 客户端加入“电池优化白名单”，并锁定系统后台卡片，防止系统激进的杀后台机制切断正在进行的长时间下载任务或远程 SSH 会话。
